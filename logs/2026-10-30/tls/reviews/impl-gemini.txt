  As noted in [LeanHttp/Client.lean:782-784](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Client.lean#L782-L784) and [NOTES.md:205](file:///home/matthias/prog/lean-http-wt-tls/NOTES.md#L205), a libuv timer can fire up to 1 ms early relative to `IO.monoMsNow`. - **Confidence**: High.
- **Fix**: In [`handshake`](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Transport.lean#L253-L254), if `deadline ≤ timeoutAt`, the timer was waiting for `deadline`, so a timer expiry is always `.deadline`:
  ```lean

    return if deadline ≤ timeoutAt || deadline ≤ (← IO.monoMsNow) then .deadline else .timedOut
  ```

### 4. [Medium] [`Tls.serverName`](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Tls.lean#L298-L306) only checks for ASCII digits and dots, missing hex/mixed IPv4 host strings (`0x7f.0.0.1`, `0x7f000001`, `127.0.0.0x1`)

- **Location**: [LeanHttp/Tls.lean:298-306](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Tls.lean#L298-L306) ([`serverName`](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Tls.lean#L298-L306)).
- **What goes wrong**:
  [DESIGN.md:125](file:///home/matthias/prog/lean-http-wt-tls/DESIGN.md#L125) and [LeanHttp/Tls.lean:294-296](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Tls.lean#L294-L296) state that host strings which `URI.parse?` parses as `URI.Host.name` because they are not strict dotted-decimal `a.b.c.d`, yet which the system resolver (`getaddrinfo` / `inet_aton`) accepts as IPv4 addresses, must be refused as a setup error rather than sent in SNI and verified as DNS names (`SSL_set1_host`).
  [`Tls.serverName`](file:///home/matthias/prog/lean-http-wt-tls/LeanHttp/Tls.lean#L303-L304) only tests:
  ```lean
  else if s.all (fun c => c.isDigit || c == '.') then
    .error s!"the host name {s.quote} is all digits: write an IPv4 address in full, a.b.c.d"
  ```
  Hex or mixed forms such as `https://0x7f000001/`, `https://0x7f.0.0.1/`, or `https://127.0.0.0x1/` contain `'x'` / `'a'..'f'`, so `URI.parse?` produces `URI.Host.name`, `Tls.serverName` returns `.ok (.host s)`, glibc `getaddrinfo` resolves them to `127.0.0.1`, and OpenSSL sends them as SNI and checks `dNSName` instead of `iPAddress`.
  Additionally, if a user constructs `URI.Host.name` directly in Lean rather than via `URI.parse?`, `serverName` does not reject trailing dots or empty labels (`"example.com."`, `"a..b"`).
- **Confidence**: High.
- **Fix**: Per RFC 1123 §2.1 / WHATWG URL host rules, split `s` on `'.'`, reject any empty label, and reject any host whose final label starts with an ASCII digit (no valid DNS TLD begins with a digit, whereas every decimal, octal, or `0x` hex IPv4 form has a final label starting with `'0'..'9'`).
